# 灰泽满

作者：栗帽 · 形象 3.4.0 · 发布修订 r6

## 安装

1. 下载并解压 [发布包](hazel-3.4.0-r6-release.zip)。
2. 将解压目录交给 Agent，按包内 [AGENTS.md](AGENTS.md) 安装。

仅使用形象时，在 Coopanion 装扮页导入包内 `hazel-3.4.0.zip`。
